# Design tokens — addYknow (redesign leve)

Fonte de verdade: `src/app/globals.css` (`:root`).

## Cores

| Token | Valor | Uso |
|-------|-------|-----|
| `--teal` | `#3db8b0` | Accent / botões primários |
| `--teal-dark` | `#1f7a74` | Texto accent / estados activos |
| `--teal-soft` | `#5ec9c2` | Hover / dark accent |
| `--teal-mist` | `#e8f7f6` | Fundos suaves / nav activa |
| `--bg` | `#f7f9fb` | Fundo principal |
| `--bg-elevated` | `#ffffff` | Cards / superfícies |
| `--bg-soft` | `#eef3f7` | Fundos secundários |
| `--fg` | `#1a2332` | Texto principal (grafite) |
| `--fg-muted` | `#6b7785` | Texto secundário |
| `--income` | `#3d9b6e` | Entradas / positivo |
| `--expense` | `#d4706a` | Despesas / negativo |
| `--warn` | `#c4922a` | Alertas |

`--navy*` mapeia para `--teal*` para compatibilidade com CSS legado.

## Tipografia / espaço / raio

- `--font-display`: Fraunces
- `--font-body`: Manrope
- `--text-money`: valores financeiros hero
- `--radius` / `--radius-sm` / `--radius-lg`
- `--shadow-soft` / `--shadow-lift` (discretos)
- `--dur-fast`: 120ms (microinterações)
