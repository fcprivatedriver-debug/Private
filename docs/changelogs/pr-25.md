# ZRIK PR #25 — Aplicação operacional

## Changelog

- Cliente Prisma dual: TCP para PostgreSQL local + adapter Neon em serverless
- `scripts/ensure-env.mjs` carrega `.env` automaticamente no build local
- Integração Stripe com SDK (`stripe`): PaymentIntents reais com chave válida; modo demo com cartão 4242 quando a chave é placeholder
- Autocomplete de endereços via OpenStreetMap Nominatim sem `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`
- Smoke scripts: `scripts/smoke-register.ts`, `scripts/smoke-booking-flow.ts`
- Checkout Stripe com copy de demonstração clara

## New features

- App local funcional em http://localhost:3000/pt
- Fluxo completo: registo → login → pedido → oferta → pagamento Stripe demo → confirmação
- Planeador de viagem com estimativa de rota (OSRM/Nominatim) e mapa embed
- Painéis cliente, motorista e administração operacionais com seed demo
