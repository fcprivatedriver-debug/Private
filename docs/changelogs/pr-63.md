# Changelog — PR #63

## O que mudou

Hotfix pré-merge (revisão do PR #62 / teste Android real):

1. **Fatura sem câmara automática** — ao escolher Fatura, abre o ecrã com «Tirar fotografia / Escolher fotografia / Escolher PDF». A câmara só abre após toque explícito. `auto=1` removido deste fluxo; voz intacta.
2. **Storage Bytes** — causa raiz documentada: o source já usava `decode(base64)` + `nina."StoredObject"` (#48/#54). A assinatura `prisma.storedObject.create(Bytes)` **não existe** nos caminhos de write. Regressão repo-wide impede o reaparecimento.
3. **UI** — nunca mostra erro e «Fatura guardada.» ao mesmo tempo. Sucesso só com persistência confirmada (`ok` + `receiptUrl`). Sem Prisma/Neon/stack ao utilizador.
