# PR #43 — Dados externos (sync / cache / MEL)

## Changelog

- Pipeline de sincronização addYknow: fonte → normalize → BD → MEL/app.
- Sync automático **MOBI.E Lisboa (CC0)** — 157 carregadores reais nos testes.
- Sync **DGEG combustíveis** implementado mas **desligado** até Partilha de Informação (uso comercial proibido no portal).
- Importação manual CSV/JSON para Continente, Pingo Doce e Auchan (auto-sync impossível).
- Cron protegido (`CRON_SECRET`) e painel admin `/pt/admin/dados-externos`.
- Novas tools MEL: combustível, carregadores, comparação de cesto — só cache real + frescura.
- Regra mantida: **dado real + fonte + timestamp, ou indisponível.**

## Novas funcionalidades

- Cache Prisma de postos, preços, carregadores e produtos externos
- «Atualizar agora» por fonte (admin técnico)
- Importação validada de produtos sem destruir dados anteriores
- Labels «Atualizado há X» / stale
- Cron Vercel para MOBI Lisboa (diário) e DGEG (6h se autorizado)
