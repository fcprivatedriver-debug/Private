# PR 26 — Mel: Assistente Pessoal Inteligente

## Changelog

Substituição completa do marketplace ZRIK pela **Mel**, uma assistente pessoal inteligente para Web e PWA (Android / iPhone), com arquitectura modular preparada para expansão.

### Ronda recente — Tarefas ↔ Agenda ↔ Calendário + Objectivos

- A Agenda deixa de ficar vazia quando existem tarefas com data: reconciliação `task-sync` + fallback de merge.
- Criar / editar / concluir / eliminar tarefa com data reflecte-se automaticamente na Agenda e no Calendário.
- Área **Objectivos** fechada: hábitos editáveis (incluindo frequência), marcar/desmarcar hoje, progresso semanal.
- Seed demo cria eventos `task-sync` e activa o módulo HABITS.

## Novas funcionalidades

- **Autenticação** por e-mail e palavra-passe (registo + login)
- **Biometria / PIN** após o primeiro login (flags + UI em Definições; WebAuthn detectado)
- **Hoje** — dashboard do dia com agenda, tarefas e conversa com a Mel
- **Tarefas** — criar, concluir, prioridades e prazos (com ou sem hora)
- **Agenda / Calendário** — dia / semana / mês; tarefas com data e eventos no mesmo sítio
- **Sync Tarefas → Calendário** — eventos `task-sync` via event bus + backfill
- **Captura por voz e texto** — Web Speech API + parser em português → tarefa / evento / lembrete
- **Objectivos / Hábitos** — CRUD, check-in diário com desmarcar, frequência editável
- **Relatórios semanais** — métricas, destaques e histórico
- **PWA** — manifest, service worker, ícones, instalável
