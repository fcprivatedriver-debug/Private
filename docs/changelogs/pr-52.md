# PR #52 — Fotografia / digitalização de faturas

## Changelog
- Captura Instantânea com câmara, galeria e PDF em inputs separados (Android/mobile).
- Upload valida JPEG/PNG/WEBP/PDF e limite de 5 MB com erros claros.
- Fatura persistida em `StoredObject` (PostgreSQL/Neon); recuperável após logout/login.
- `/api/uploads` serve também faturas ainda não ligadas a uma despesa (órfãos da família).
- OCR sem valores fictícios: mensagem honesta + introdução manual do valor.
- Nova despesa aceita `?receipt=` para pré-anexar a fatura fotografada.

## Novas capacidades
- Tirar fotografia / escolher foto / escolher PDF na Captura e na página de faturas.
- Guardar fatura mesmo sem motor OCR real.
- Registar despesa manualmente com a fatura já anexada.
- Ver ficheiro guardado antes de confirmar a despesa.
