# Changelog — PR #41

## O que mudou

A MEL (assistente da addYknow) passa a poder usar a API OpenAI **no servidor**, com function calling, para compreender perguntas e explicar resultados. Os **valores financeiros continuam a ser calculados pela aplicação** (Prisma / agregações), nunca inventados pelo modelo.

Sem `OPENAI_API_KEY`, a MEL mantém o fallback rule-based existente (`answerNina`) — a app não bloqueia.

## Novas funcionalidades

- Integração OpenAI (SDK oficial) com modelo configurável (`OPENAI_MODEL`, default `gpt-4o-mini`)
- Tools READ seguras: resumo, despesas por categoria, receitas, orçamento, poupanças/objetivos, resumo familiar
- Isolamento pessoal vs Conta Familiar (sessão + `expenseScopeWhere` / etc.)
- Rejeição de `userId` / `familyId` / `memberId` injectados pelo modelo
- Tabela `MelUsage` + rate limit mensal (`MEL_MONTHLY_LIMIT`)
- Histórico curto via `AiInsight` (kind=`chat`)
- UX do chat: indicador “A MEL está a responder…”, erros elegantes, anti-duplicados, aria-labels, avatar **M**
