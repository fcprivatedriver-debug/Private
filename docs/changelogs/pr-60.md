# PR #60 — Cabeçalho identidade Pessoal/Familiar + fotografia

## Changelog

- Topbar deixa de repetir marca + “Família” e passa a mostrar **só o nome do contexto activo**.
- Avatar circular maior, com foto do utilizador (Pessoal) ou da família (Familiar).
- Toque no avatar: tirar foto / galeria / remover, com validação e erros amigáveis.
- Fotografias persistentes em Neon `StoredObject` (`profiles/…`) + `User.image` / `Family.image`.
- Seletor **Pessoal | Familiar** com estado activo em azul-petróleo (`#245563`) e texto branco.
- Migração `Family.image`.

## Novas funcionalidades

- Identidade contextual no cabeçalho (nome + foto).
- Upload/remoção de fotografia de perfil pessoal e familiar.
- Persistência após refresh e logout/login.

## Não alterado

Compras, MEL, navegação inferior, auth, Resend/email, restante dashboard.

## Onde ficam as fotografias

| Camada | Local |
|--------|--------|
| Bytes | Postgres/Neon tabela `StoredObject` |
| Key | `profiles/user/<userId>/…` ou `profiles/family/<familyId>/…` |
| URL | `/api/uploads/profiles/…` |
| Referência Pessoal | `User.image` (+ sync `FamilyMember.photoUrl`) |
| Referência Familiar | `Family.image` |
